Checks on this computer

Your Veto server (optional)

Run npm start in the Veto folder. Then links that are not clearly safe are also checked online (where they really lead, what the page asks for, how old the domain is), and the AI check can use the server's Claude key. Only the address goes to your own server.

AI second opinion (optional)

Used for messages the rules cannot read (other languages: the AI translates them) and when the rules and the text model disagree. The AI can add a warning, never remove one. Personal data (card numbers, codes, phone numbers, e-mails) is removed before the text is sent. The Veto server's AI is used first when it has one; otherwise your Groq key.
