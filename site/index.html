Scams do not wait for you to ask

Other checkers make you copy a suspicious message, open an app, paste it and ask "is this fake?". By then people have usually tapped. Veto never waits to be asked: it reads each new notification on the phone, checks it against the rules of the institution it claims to be, and only appears when something needs you.

How the app works

The Android app is the full product. It reads only the sender and text of new notifications (WhatsApp, SMS, Telegram), on the phone; trusted family chats are skipped; nothing is uploaded. It stays current by refreshing public phishing feeds, the day's newly registered domains and new look-alike certificates, and scams people report through Veto go to the police with an evidence pack.

Install in 3 steps (Android blocks apps with these powers when they come from outside Google Play):
  1. Tap Android app. If Android asks, allow installs from your browser.
  2. If Play Protect blocks it: open the Play Store, tap your profile, Play Protect, the settings gear, switch off "Scan apps with Play Protect", install Veto, then switch it back on.
  3. To turn on message reading: Settings, Apps, Veto, the ⋮ menu, "Allow restricted settings", then switch on each guard in Veto.
The phone it was recorded on had it installed directly over a cable, the way developers install test builds. If it will not install, the web app has the same checks, without the automatic watching (a browser cannot read notifications or calls).

How we built and tested it

Every test was planned in writing before it ran, used data from after the training data, and every number is traced to a file in the public repository.

472,582

dated public URLs trained the link model (OpenPhish history, Phishing.Database, PhiUSIIL and real websites)

33,766

held-out links tested later: 98.3 % precision, 94.5 % recall, 0.59 % false alarms

292,437

phishing links from a second feed, on domains never seen in training: 89.0 % caught

881

labelled SMS in nested 5-fold cross-validation: 96.9 % of scams caught; a 1,000,000-text generated set was tested too

917,396

look-alike domains of 92,732 brands in a stress test, with 100,000 real sites as controls

736,333

live certificates read in one 10-minute run from 50 logs (1,190 a second)

2,231

official UAE government and bank pages: 0 wrongly flagged

153

automated tests, plus browser tests of the extension and the phone engine
